# Standup Telegram bot

## Настройки

Бот читает `.env` рядом с `index.js`. Переменные окружения PM2 имеют приоритет:
`TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`, `API_KEY_GIPHY`, `YANDEX_OAUTH_TOKEN`.
Новый токен после `/revoke` в BotFather внесите в существующий `ecosystem.config.js`
в `apps[].env.TELEGRAM_TOKEN` (или используемый `env_production`), затем перезапустите PM2.
Не заменяйте существующий конфиг примером: в нём могут находиться ваши настройки.

## Ручная отправка

Из каталога проекта на сервере:

```bash
npm run send:standup
npm run send:tea
npm run send:worklog
```

Команда отправляет сообщение сразу и завершается, не запускает расписание.
Читает `env` приложения `jet-standups-bot` из локального `ecosystem.config.js`, затем `.env`.
Для настроек `env_production`: `PM2_ENV=production npm run send:standup`.
Стандартная проверка праздничного дня сохраняется. Для отправки даже в выходной:

```bash
npm run send:standup -- --force
npm run send:tea -- --force
```

Каждый запуск отправляет новое сообщение; повторный запуск может создать дубликат.

## PM2 и восстановление после перезагрузки

В существующий `ecosystem.config.js` добавьте параметры из `ecosystem.config.example.js`:
`cwd: __dirname`, `autorestart: true`, `restart_delay: 5000`, один экземпляр.
Пример не содержит токенов. Затем под тем же пользователем, который запускает бота
(на скриншоте — root):

```bash
pm2 startOrRestart ecosystem.config.js --update-env
pm2 startup
```

Если `pm2 startup` напечатал команду, выполните её. Затем:

```bash
pm2 save
pm2 status
pm2 logs jet-standups-bot --lines 100 --nostream
```

Если используется `env_production`, добавьте `--env production` к `startOrRestart`.
PM2 перезапускает упавший процесс; системная служба PM2 восстанавливает сохранённый
список после перезагрузки сервера. Пропущенные отправки автоматически не догоняются:
используйте ручную команду. Доступа к серверу из этого проекта нет — команды нужно
выполнить на хосте после обновления кода.

## Расписание и резервные изображения

Время — `Asia/Yekaterinburg`: стендап в 09:30 пн–сб, чай в 16:00 пт,
ворклоги в 18:00 чт. Стендап и чай пропускают праздники календаря 2026 года.

Стендап: Яндекс.Диск → случайная GIF из Giphy по существующим поисковым словам
→ текст. Для чая: Giphy → текст. Резерв Giphy требует `API_KEY_GIPHY`.
Копия картинок на другом диске не требуется. Запросы имеют таймауты.
Файл Яндекса перемещается в архив только после успешной отправки этой картинки;
при ошибке изображения остаётся на исходном месте. Ошибка закрепления не отменяет отправку.
Логи новых запросов не печатают токен. Старые логи PM2 могут содержать отозванный токен.
